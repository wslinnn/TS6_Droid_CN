# release-notes — 手写发行说明

发版前把本版本的中文发布说明写在 `vX.Y.Z-Han.md`（与 tag 严格同名）。
发布工作流会把这个文件整体作为 Release body（`body_path`），所以
**文件内容必须自成一体的完整正文**，对齐仓库既有 Release 的三段式结构：

1. `## 简介 / Overview`——本版本主题的一段话 + 上游致谢与 GPLv3 声明
2. `---`
3. `## 更新日志 (Changelog)`——分组小标题（emoji 前缀），只写本版本的更新与修复
4. `---`
5. `## 📥 安装说明`——上一版用户升级路径（应用内检查更新 / Assets 覆盖安装）、
   系统版本要求、完整变更清单 compare 链接

要点：

- Release **名称**由发布工作流生成，格式 `TS6 Mobile vX.Y.0`（tag 的 `-Han`
  后缀不带进名称）——由工作流维护，正文文件无需关心
- 历史版本说明可在 Git 历史里追溯，文件随版本落库、过期不删
- 本页正文即发布后 GitHub Release 的最终形态；发布后一般无需再用 API 替换
