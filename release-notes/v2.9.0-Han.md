## 简介

TS6 Mobile v2.9.0-Han：主页换悬浮胶囊 Tab Bar（列表全屏正常滚动、条目掠过胶囊之下），掉线重连与麦克风采集可靠性加固。

## 界面

- **主页悬浮胶囊 Tab Bar**：主页/设置页签装进一枚浮在底部的胶囊，选中态白色高亮块以弹簧动画滑动；胶囊不占布局高度，列表铺满全屏正常滚动、条目从胶囊底下掠过
- **独立加号圆钮**：胶囊右侧分离的圆形按钮唤起添加服务器面板，显隐不影响胶囊位置
- **磨砂/玻璃材质机制上线**：共享的壁纸模糊烘焙管线 + 玻璃面板组件（投影抬升、内阴影、顶部高光、发丝描边），服务器页底栏接入试点；悬浮胶囊为固定半透明浅底——身后先可见列表条目、下层透出壁纸

## 稳定性

- **意外掉线自动重连**：退避升级为 3s 起倍增、60s 封顶、8 次尝试（总窗口约 4.5 分钟，服务器重启场景撑得住）；重连成功自动回到掉线前所在频道；重连尝试失败期间保持前台通知与唤醒锁，避免服务退为后台被国产 ROM 秒杀、重连静默夭折
- **麦克风采集自愈 + 看门狗**：录音器读错误/连续空读/连续全零帧（数字静音指纹）自动带退避重建；服务层 30s 看门狗兜底采集协程意外终止、阻塞读卡死两类静默故障——针对"对方听不到我"
- 设置页新增「电池优化白名单」「应用信息与权限」入口（国产 ROM 后台限制的常见缓解手段）

## 修复

- 混音解码缓冲残留：短帧解码不再把上一帧/上一说话人的残留叠进混音输出
- 重连后密聊目标自动重新下发：修复重连后界面显示"密聊中"而语音实际走频道的隐患

## 安装

- 直接覆盖安装上方签名 APK（`TS6-Mobile-v2.9.0-Han-release.apk`），与旧版本数据兼容
- SHA-256 校验值见同名 `.sha256` 文件，或 Release 中同名资产
- 已开启 R8 混淆，排查崩溃请配合 Release 中的 mapping.txt（Actions 构件归档）
