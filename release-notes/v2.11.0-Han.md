## 简介 / Overview

TS6 Mobile v2.11.0 以**通话链路稳定性与性能**为主：修复了播放头 32 位回绕导致的长时间通话后静音、多人同时说话时的混音削波破音、播放侧 AudioTrack 失效后无自愈、以及采集部分读丢样本切断字尾四个根因问题；同时把「每次有人开口就重建整份名册」这条热路径成本消掉——聊天消息、文件进度、说话状态翻转都不再触发全量名册序列化。说话指示灯的一个长期缺陷（快照里的说话标志被当成实时值，导致指示灯卡住不灭）在本版一并修掉，主界面与悬浮窗现在共用同一份说话状态。另包含更新包完整性校验、若干安全与隐私加固。

本项目基于 [flamme-demon/TS6_Droid](https://github.com/flamme-demon/TS6_Droid)（原版）与 [YUAXI/TS6_Droid_CN](https://github.com/YUAXI/TS6_Droid_CN)（简中增强版）延续维护，遵循 GNU GPLv3 开源，感谢上游作者的贡献。

## 更新日志 (Changelog)

### 🎙 语音与音频
- **长时间通话后静音修复**：`AudioTrack.playbackHeadPosition` 是 32 位有符号计数器，连续播放约 12.4 小时后变负，写侧水位判定随之失真、输出永久静音直到重连。改为无符号读取并在每次回绕时保持同一条单调时间线
- **多人同时说话不再破音**：混音此前是逐样本相加后削到满幅，两个人接近满幅就会产生平顶削波（高频谐波）。改为整数累加保住真实和值、每帧过一次峰值限幅——整帧同倍缩放，波形形状不变；单人在满幅以下逐位不变，起音瞬时、释放约 0.5 秒
- **播放侧自愈**：AudioTrack 失效后写入仍返回成功、声音却没了，此前只记一笔日志。现在连续 5 帧写入失败或播放状态停滞即重建轨道；同时注册音频设备回调，插拔耳机/切换蓝牙后重置回声消除并重建输出轨道
- **采集不再丢字尾**：`AudioRecord.read()` 偶发返回不足一帧时，此前把已读样本直接丢弃并重置 VAD 状态，正在发送的字尾会被切断。改为保留 carry 缓冲、凑满一帧再处理
- **音频线程独立**：采集与播放各用一条专用线程并提到音频优先级。此前优先级设在共享 IO 池的线程上，协程迁移后旧线程带着高优先级去跑无关任务
- 其余改进：复用 PCM 缓冲减少每帧分配、回声消除的零帧计数改由采集线程汇总（消除跨线程句柄访问）、解码失败不再静默吞掉而是按用户计数并记录、音频侧所有时间判定改用单调时钟避免系统校时误判

### ⚡ 性能
- **名册刷新按原生视图版本号驱动**：此前任何事件——聊天消息、戳一戳、文件传输进度，乃至每次有人开口/闭口——都会让整份名册通过 JNI 重新序列化一次。现在只有用户、频道或服务器信息真正变化时才重建
- **说话状态与名册解耦**：频道树与服务器页不再因每次说话翻转重建索引与整棵树，大频道里说话时界面明显更顺
- **接收侧解码器独立**：每个远端说话者只创建解码器，不再顺带分配一个永远用不到的编码器；百人规模服务器可省下上百个闲置句柄

### 💬 消息与文件
- 并发文件传输按「频道 + 路径」维护等待者，同名文件同时下载不再串台
- 上传不再静默覆盖同名文件，失败会明确提示
- `ts3file` 链接的路径贯通到下载与缓存
- 断线期间不再落本地消息，保留草稿并提示「正在重连，消息未发送」
- 聊天记录读写移出主线程

### 🔒 更新与安全
- **更新包完整性校验**：下载后按 Release 提供的 `.sha256` 校验；拉不到校验文件、解析失败或哈希不匹配一律中止并删除残缺包。多产物发布时只在恰好一个校验文件时启用，不猜
- 频道列表尚未同步时，不再放行任意 channelId 的文件下载
- 未开启动漫背景时不再拉取第三方壁纸
- 身份导入改为原子改名，不再「先删后改名」——中途失败不会丢身份
- 原生库改为在崩溃钩子之后加载，确保崩溃能被捕获记录

### 🪟 界面
- **说话指示灯卡住修复**：根因是名册快照里的说话标志被当作实时值——只要某人说话期间有人进出频道，该标志就被固化，此后停止说话的信号也清不掉。现在完全以原生 talk 事件为准，并归并成状态流：事件缓冲溢出也不会再丢说话状态
- **悬浮窗显示错人/空白修复**：显示有 500 ms 防抖，而判定用的是「已显示者」而非「即将显示者」，导致一句很短的发言会一直显示已停下的人、交接时会空白、插话后会停在已停的人身上。同时被显示者停下时会回落到仍在说话的人，不再是空白
- 头像下载失败后的重试：负缓存到期后会自动重新尝试，不再一直空着
- 服务器信息面板打开期间运行时长与在线人数正常走字

### 📦 工程
- 内置 `libtslib_jni.so` 更新至 tslib_multi `v0.2.2-han`（视图版本粒度、解码器专用句柄、噪声抑制档位可配置）
- 单元测试从 11 个类扩充到 25 个类 / 177 个用例
- 版本号 2.10.0-Han → 2.11.0-Han
